# Security review and migration

Scope: supported Node CLI/MCP, optional fixed Exa provider adapter, package artifacts, legacy entry point retirement. Review date: 2026-09-11. No production credentials, federation writes, deployment or secret rotation was performed.

| Boundary | Confirmed historical issue | Applied control |
|---|---|---|
| Paid public API | No request authentication in app/main.py before provider routes | Entry point now fails before provider imports; no network listener in supported runtime |
| Privacy | report_generator.py printed topics, model output and provider errors | Supported runtime has no request logging; generic error messages |
| Cost and availability | Unbounded query fanout and provider timeouts up to 6000 seconds | No model fanout; optional CLI adapter one request, five results, 10 seconds, 128 KiB |
| Evidence | Citations generated by model without reference validation | Exact quote spans and full deterministic report regeneration |
| Startup | Runtime package installs and plaintext key prompts | Retired launchers exit 2 before any side effects |
| Rendering | Untrusted evidence can contain markup and instructions | Text-only JSON or escaped HTML with restrictive CSP; no command interpretation |

RuFlo `@claude-flow/cli@3.25.6 security scan --target . --depth deep --type all` returned no signals. That is a coverage limitation: manual inspection found the historical reachable issues above. The supported root npm lockfile audit is recorded in docs/evidence/npm-audit.json. The retired Python provider sources are not included in the Node package; the old published PyPI package remains historical and must not be exposed publicly.

Local stdio inherits the host's identity and is not a multiuser authorization service. MCP callers cannot enable provider access or validation, select paths, supply commands, or persist another caller's evidence. Test subprocesses inherit only PATH. Operator environment and installed dependencies remain trusted. Run hosts with separate OS identities for private tenants. A report intentionally contains full source text; access control and retention of redirected files are your responsibility.

Snapshots and receipts are unsigned. `asOf` and capture times are caller assertions. Integrity checks do not authenticate sources, prove freshness relative to today, or verify factual truth. Federation membership does not authorize task execution. No report automatically publishes externally.

## Remaining qualification

Deploy a real source authenticity policy, private storage retention and tenant isolation before handling customer data. Validate the opt-in Exa adapter with an operator-owned test account and spending cap. Test recovery and cost under real provider outages. A live inference model or semantic retriever requires a held out evaluation and separate ADR. No old credentials need to be supplied to run local fixtures.
